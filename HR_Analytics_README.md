# HR Analytics Dashboard | Power BI

## Project Overview
An interactive HR Analytics Dashboard built using Microsoft Power BI to explore workforce data containing 6,000+ employee records.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Dashboard Highlights
- Total employee count
- Active and terminated employee counts
- Employee termination rate
- Minimum, maximum, and average base salary
- Top 5 departments by employee count
- Interactive Department and Employment Status slicers
- KPI cards and visual summaries

## Project Objectives
- Understand workforce distribution across departments.
- Monitor active and terminated employees.
- Summarize salary information.
- Explore HR metrics through interactive filters.

## Repository Contents
- `HR_Analytics_Dashboard.pbix` — Power BI dashboard file
- `README.md` — Project overview
- `HR_Analytics_Documentation.md` — Detailed project documentation and DAX measures
- `screenshots/` — Dashboard screenshots (optional)

## How to View
1. Download `HR_Analytics_Dashboard.pbix`.
2. Open it using Microsoft Power BI Desktop.
3. Use the slicers to explore the dashboard.

## Outcome
The dashboard brings important HR metrics into one interactive report, making it easier to review workforce trends and salary statistics.

## Note
Ensure the dataset is permitted for public sharing and that no confidential or personally identifiable employee information is included in the published files.
